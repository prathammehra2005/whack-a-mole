# Whack-A-Mole Game

A simple Whack-A-Mole game made using Java Swing.  
The project is based on object-oriented programming concepts and includes score tracking, different mole types, and a basic GUI.

## Features

- GUI made with Java Swing
- Score tracking
- Different mole types
- High score system
- Exception handling
- OOP based structure

## Technologies Used

- Java
- Java Swing
